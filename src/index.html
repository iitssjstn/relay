Nog geen AI ingesteld. Klik links op "AI toevoegen aan de ketting", vul een API-key en model in, en begin het gesprek. Voeg gerust meerdere AI's toe — Relay schakelt automatisch door als de actieve AI zijn contextlimiet bereikt.

API-keys en gesprekken worden bewaard bij jouw account op deze Relay-server. Berichten lopen via de Relay-server naar de AI-provider die je zelf kiest (dat voorkomt browserblokkades bij sommige providers) — de server bewaart of leest de inhoud daarvan niet. Log volgende keer gewoon in om verder te gaan.

AI toevoegen

Vul de gegevens van een AI-provider in. Deze wordt onderaan de ketting toegevoegd.
Wordt gebruikt om via de Relay-server met de AI-provider te praten (dat voorkomt browserblokkades bij sommige providers), en bewaard in de database van deze Relay-server, gekoppeld aan jouw account. De server leest of bewaart de inhoud van je gesprekken met de provider niet, stuurt 'm alleen door.
Toont het redeneerproces van het model als inklapbaar "Nagedacht voor Xs"-blokje boven het antwoord. Werkt alleen bij Claude-modellen die dit ondersteunen (bv. Claude 4-serie), en kost extra tokens/tijd.
Let op: elke provider heeft zijn eigen gebruiksvoorwaarden. Gebruik deze tool alleen met API-keys waar je zelf recht toe hebt, en respecteer de auteursrechten en herpublicatie-regels van de betreffende aanbieder — output van een AI-model overnemen als eigen werk of zonder toestemming commercieel herpubliceren kan in strijd zijn met die voorwaarden.

GitHub toevoegen

Plak een link naar een los bestand (…/blob/…) of naar een hele repo (github.com/eigenaar/repo) — de inhoud wordt opgehaald en meegestuurd met je volgende bericht.
Bij een hele repo worden de belangrijkste bestanden opgehaald (README, configbestanden, broncode) tot een redelijke grens — mappen als node_modules, .git en gebouwde bestanden worden overgeslagen. Voor privé-repo's heb je een GitHub-token nodig — zie "GitHub" onderaan de zijbalk.

GitHub

Optioneel: een Personal Access Token, alleen nodig om bestanden uit privé-repo's op te halen of om de (vrij lage) anonieme limiet van GitHub te omzeilen. Zonder token werkt het gewoon voor openbare repo's.
Aanmaken via GitHub → Settings → Developer settings → Personal access tokens. Voor privé-repo's is scope "repo" (of "Contents: Read-only" bij fine-grained tokens) genoeg.

E2B (sandbox)

Nodig om de "Uitvoeren"-knop bij code te gebruiken: laat een AI-gegenereerd script écht draaien, in een geïsoleerde omgeving bij E2B — niet op deze server. Gratis account met startsaldo op e2b.dev.
Te vinden op e2b.dev onder Dashboard → API Keys, na het aanmaken van een (gratis) account.
